## 🧪 Integration workshop

This level has no numbered modules: it's a hands-on workshop that combines this course with your other courses.

```text
TypeScript   Frontend / Web
     ↓
Python       AI / Backend / Orchestration
     ↓
C++          Performance-critical components (via pybind11-style bindings)
```

- [ ] Profile a Python workload and identify a genuine hot spot
- [ ] Implement the hot spot in C++ (numerical kernel, parser or algorithm) with Python bindings
- [ ] Package the native module so `pip install` builds or installs it
- [ ] Benchmark Python vs NumPy vs C++, and write up when the extra complexity is worth it
