# Final Python Assessment

[🏠 Course](../../README.md) · [🗺️ Roadmap](../../ROADMAP.md) · ⏱️ about 2 weeks

## 🎯 Brief

You don't graduate because you reached Module 226. Eight examinations prove you're an engineer who happens to use Python.

## ✅ Sections / requirements

- [ ] 1. Language: object model, references, mutability, decorators, descriptors, generators, iterators, async, GIL, GC, typing, imports
- [ ] 2. Coding: no frameworks, pure Python
- [ ] 3. Algorithms: unseen problems, with complexity explained
- [ ] 4. Debugging: broken production-style systems to diagnose
- [ ] 5. Backend: build an API from requirements
- [ ] 6. Concurrency: choose async / threads / processes / workers, and defend it
- [ ] 7. AI engineering: a working AI pipeline from raw requirements
- [ ] 8. Architecture defence: e.g. an AI tutoring platform for 5 million learners

Pass mark: **70% in every section.**
